# 焙刻 Roastery

A specialty coffee brand designed end to end with artboards: one design system
carried across a customer app, a barista order board and a manager console.

```bash
node src/cli/main.ts dev examples/roastery/index.tsx     # review and comment in the viewer
node src/cli/main.ts lint examples/roastery/index.tsx    # type-check, lay out, check every board
```

| Board | Size | What it shows |
|---|---|---|
| `Foundations` | 1200 wide | colour and type tokens, every component state, the icon set |
| `Home` | 390 × 844 | promo banner, category chips, product grid, floating cart, frosted tab bar |
| `ProductSheet` | 390 × 844 | bottom sheet over a dimmed screen: options, price, add to cart |
| `Checkout` | 390 × 844 | pickup store, cart lines, coupons and points, pay bar |
| `OrderTracking` | 390 × 844 | map with route, pickup code, progress steps, barista |
| `Membership` | 390 × 844 | gradient member card, stats, perks, order history |
| `BaristaBoard` | 1194 × 834 | dark kitchen display: queue / making / ready lanes, urgency |
| `Dashboard` | 1440 × 900 | KPIs with sparklines, hourly chart, category donut, stock table |
| `DashboardStates` | 1200 wide | empty, error and loading (skeleton) states |

## Files

- `tokens.ts` — colours, type scale, radii, shadows, gradients
- `components.tsx` — typed components shared by every surface (Button, Chip, Badge, Price, Input, TabBar, charts…)
- `mobile.tsx`, `kiosk.tsx`, `admin.tsx`, `foundations.tsx` — the boards; `index.tsx` lists them in canvas order
- `data.ts` — sample products and the imported product images
- `assets/*.jpg` — product photos (AI-generated from one shared style prompt, 3:2 with the subject centred so every crop — card, sheet banner, circle, thumbnail — keeps it)
- `icons.ts` — Lucide outlines flattened to one path each, generated by `tools/gen-icons.mjs`

Components are written in TSX with prop types: in plain `.jsx`, a default such as
`width = "fill"` is inferred as `string` and fails the type check where a `Size` is expected.
